macOS 藏起来的显示器控制，都装进这一个菜单栏面板。

Crisp 免费开源，是一款 macOS 外接显示器控制面板：HiDPI 缩放、DDC 亮度、预设，连 BetterDisplay 和 Lunar 的部分收费功能也免费。

下载 macOS 版 GitHub 仓库
$ brew install --cask crisp 点击复制

开源（MIT），已收录于 awesome-mac。

macOS 偏心 Apple 自家的显示器，对其他品牌的却总是敷衍：文字发虚或小得看不清，亮度键说罢工就罢工，能救场的控制选项还被系统藏了起来。Crisp 补上这个缺口，让每一块显示器都能被认真对待。显示器正发虚？从这里开始。

一块面板，把每块屏都调到位。

任意显示器都能开 HiDPI

给外接显示器补上 Retina 级的缩放分辨率，不再发虚或太小，2K 及以上自动配好，且始终跑满面板刷新率。

平滑缩放

以更小的步进微调界面大小，远超 macOS 默认的那几档。很多人当初装 BetterDisplay，就是为了这种灵活缩放，现在内建了。

哪块屏都能调亮度

外接屏走 DDC 硬件控制，不支持的用软件兜底；键盘亮度键可作用在光标所在的屏、全部屏或你指定的几块。

额外亮度

解锁 HDR 亮度余量，把 XDR MacBook 和 HDR 显示器的亮度推过 100%。BetterDisplay 把这个功能放在 Pro 里卖，Crisp 免费。

显示器音量

通过 DDC 调外接显示器自带音箱的音量，每块屏一个滑块；当显示器是当前音频输出时，键盘音量键直接生效。

预设

把分辨率、亮度、排列存成一套，一键切换。

键盘快捷键

给任意预设分配一个全局快捷键，另有一个快捷键用来切换光标所在显示器的 HiDPI。不需要辅助功能权限。

排列

拖拽摆位、一键切换主显示器。

系统开关

深色模式、夜览、原彩显示，直接在面板里切，不用进系统设置。

色彩

ICC 配置切换、每块屏独立开关 HDR，外加 gamma、对比度、增益微调。

虚拟显示器

创建 HiDPI 虚拟屏，用于直播、随航或无头 Mac。

更多

合并亮度滑块、自动亮度跟随内建屏、防止睡眠、隐藏刘海、开机启动。

所有操作，都在菜单栏里。

常见问题

没找到答案？去 GitHub 提问。

Crisp 真的免费吗？

是的。所有功能都免费：没有 Pro 分层、没有授权码、没有试用期，也没有每天的次数限制。整个 App 以 MIT 协议开源。

Crisp 安装安全吗？

安全。每个版本都经过 Apple 签名和公证，完整源代码公开在 GitHub 上，并且已通过 Microsoft Defender 检测，确认不含恶意软件，也没有任何遥测。

Crisp 会自动更新吗？

从 1.5.0 开始会。Crisp 每天在后台检查一次，发现新版本一键就能装好，不用再跳去浏览器。如果你现在用的是更早的版本，需要再手动更新一次，之后就都是自动的了。

使用 Crisp 需要什么条件？

macOS 14（Sonoma）及以上，Apple 芯片和 Intel Mac 都支持。少数功能（如从菜单断开显示器）仅限 Apple 芯片。

Crisp 和 BetterDisplay、Lunar 有什么区别？

它们通常收费的功能，灵活的 HiDPI 缩放、DDC 亮度、XDR/HDR 额外亮度、预设、排列，在 Crisp 里都免费。详见逐项对比：Crisp 和 BetterDisplay / Lunar / MonitorControl。

免费开源，MIT 许可。要求 macOS 14 及以上。
