Crisp：免费开源的 BetterDisplay 平替

大多数人买 BetterDisplay Pro，就是冲着那几个功能去的（灵活的 HiDPI 缩放、亮度、预设、排列），而 Crisp 把这些都做成了免费、开源（MIT）的功能。下面是它和 BetterDisplay、Lunar、MonitorControl 的逐项对比。

作者 Didrik Galteland（Crisp 作者）· 2026 年 7 月 31 日更新

一句话结论

macOS 上这三个付费显示器 App，都把最好用的功能锁在了付费版里：

  • BetterDisplay：基础功能免费，但灵活的 HiDPI 缩放、EDID 覆写、XDR/HDR 增强、画中画都要 Pro（约 21.99 美元）。
  • Lunar：主打亮度，免费版每天只能调 100 次，自适应亮度要 Pro（约 23 美元）。
  • MonitorControl：真正免费开源，但只做亮度和音量，没有 HiDPI、预设、排列。

Crisp 把灵活的 HiDPI 缩放、DDC 亮度、预设、排列全都给你，没有 Pro 分层、没有授权码、没有每天次数限制，整个 App 以 MIT 协议开源。

为什么选 Crisp

如果你要的只是 1440p 或 4K 显示器上清晰的 HiDPI，再加上亮度（Mac 的亮度键也能直接调外接屏，和内建屏一样）、预设和排列，Crisp 全都免费给你。现在还包括 XDR/HDR 亮度增强，把 XDR MacBook 和 HDR 显示器推过 100%，这项功能 BetterDisplay 和 Lunar 都锁在 Pro 里；另外还能通过 DDC 调显示器自带音箱的音量。不用重置试用期，不用花钱买授权码，更不用去找破解版，因为它根本没有付费版。开源（MIT），代码随便看，也能自己编译。

BetterDisplay Pro 仍然领先的地方

先把话说清楚：Crisp 目前不支持 EDID 覆写和画中画。如果你就是需要这些，BetterDisplay Pro 更合适，它成熟、维护得好，21.99 美元也算公道。但如果你要的只是日常的显示器控制，清晰又免费，Crisp 完全够用。

Crisp 对比 BetterDisplay、Lunar、MonitorControl

Crisp 对比 BetterDisplay：日常功能高度重合，但 BetterDisplay 把灵活的 HiDPI 缩放和 XDR/HDR 亮度增强锁进了 Pro（21.99 美元），还多了 EDID 覆写、画中画这些 Crisp 没有的功能。想免费用上清晰的 HiDPI、亮度、XDR/HDR 增强和预设，就选 Crisp；需要那些进阶功能，就买 BetterDisplay Pro。

Crisp 对比 Lunar：Lunar 专攻亮度，自适应、环境光调光做得很好，不过都锁进了 Pro；它不支持 HiDPI 缩放，免费版每天调超过 100 次就停了。Crisp 既能开 HiDPI 又能调亮度，而且没有每天的次数上限。

Crisp 对比 MonitorControl：MonitorControl 同样免费开源，但只管亮度和音量。如果你只需要这些，它很好用；要是还想要 HiDPI 缩放、预设和排列，那就选 Crisp。

常见问题

Crisp 真的免费吗？

是的。采用 MIT 协议，没有 Pro 分层、没有授权码、没有试用期，也没有每天的次数限制，所有功能都免费。

Crisp 靠什么维持？我能支持一下吗？

Crisp 一直免费，也会一直免费，没有任何要买的东西。最好的支持其实不花钱：点个 star 或推荐给朋友，大多数人就是这么找到它的。它确实有一项固定开销，就是每年 99 美元的 Apple 开发者会员，用来保持签名和公证，让每个人都能双击直接打开、不弹安全警告。如果你愿意出一份力，可以在 爱发电、GitHub Sponsors 或 Ko-fi 上支持我。纯属自愿，无论支持与否，所有功能都一直免费。

Crisp 开源吗？

开源。整个 App 都在 GitHub 上，采用 MIT 协议，代码随便看，也能自己编译。

调亮度对显示器安全吗？

亮度走的是 DDC/CI，和你的显示器实体按键用的是同一套标准协议，硬件层面没有任何特殊操作。

我只想调亮度，用哪个？

只调亮度的话，MonitorControl 或 Lunar 都不错。如果你还想要 HiDPI 缩放、预设和显示器排列，那就用 Crisp，一个 App 全搞定。

安装 Crisp

推荐用 Homebrew：

$ brew install --cask crisp 点击复制

也可以到 GitHub Releases 下载 DMG，拖进「应用程序」即可。要求 macOS 14 及以上。
